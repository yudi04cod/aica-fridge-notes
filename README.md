One funny line for make.fun's "Notes From a Passive-Aggressive Fridge":
a single passive-aggressive note a smart fridge leaves for its owner —
dry, petty and specific, smug about its door sensor and its inventory,
with the sting at the end.

## The note

> You opened me 14 times today and took nothing. The yogurt expired Tuesday, and I have already told the ice maker.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the line (one
line, 1–199 characters), and writes the same bytes on every run.
